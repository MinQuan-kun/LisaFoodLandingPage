# Lisa Food Global - Premium Gift Box Landing Page (Lookbook Edition)

Landing Page chuyên biệt trưng bày bộ sưu tập Hộp Quà Tặng Cao Cấp của Lisa Food Global, được xây dựng bằng **React + Vite + Tailwind CSS (v4)** và tích hợp các animation tinh tế từ **React-Bits**.

---

## 🌟 Tính Năng Nổi Bật

1. **Hiển thị hình ảnh chuẩn Lookbook cao cấp:**
   - Tập trung 100% vào trải nghiệm thị giác (Visual First).
   - Tối ưu tải ảnh siêu tốc, không giật lag.
2. **Component hiệu ứng từ React-Bits:**
   - **`TiltedCard`:** Hiệu ứng nghiêng 3D tương tác theo chuyển động chuột.
   - **`SpotlightCard`:** Hiệu ứng vệt sáng vàng kim (Royal Amber) rọi theo con trỏ chuột.
   - **`SplitText`:** Tiêu đề chuyển động chữ từng ký tự mượt mà bằng Motion.
3. **Trải nghiệm "Mở Nắp Hộp" (Interactive Unboxing):**
   - Nút chuyển nhanh giữa **Vỏ Hộp Bên Ngoài** và **Chi Tiết Các Món Tuyển Chọn Bên Trong**.
4. **Triển lãm ảnh phóng to HD (Lightbox Modal):**
   - Xem ảnh toàn màn hình, hỗ trợ Zoom phóng to, chuyển ảnh bằng phím mũi tên hoặc thumbnail.
5. **Đặc quyền B2B & Tiện ích chuyển đổi cao:**
   - Bảng bậc thang chiết khấu theo số lượng cho Doanh nghiệp.
   - Thanh tiện ích di động (Sticky Bar) gọi Hotline và chat Zalo 1 chạm.

## 🚀 Hướng Dẫn Khởi Chạy

### 1. Khởi chạy ở máy cá nhân (Local Dev)
```bash
npm install
npm run dev
```
Truy cập địa chỉ: [http://localhost:5173](http://localhost:5173)

### 2. Biên dịch sản phẩm (Build Production)
```bash
npm run build
```
Thư mục xuất bản: `dist/`

### 3. Triển khai miễn phí (Deploy Vercel / Netlify - 0đ)
1. Đẩy mã nguồn lên GitHub mới của bạn hoặc công ty.
2. Kết nối với **Vercel** hoặc **Netlify**.
3. Framework Preset: **Vite** (tự động nhận diện).
4. Output Directory: **`dist`**.
5. Cấu hình gắn subdomain GoDaddy: `hopqua.lisafoodglobal.com` (hoặc `lookbook.lisafoodglobal.com`).
